TurboWarp Title Menu

Reusable title, menu, and DSL source storage controls for TurboWarp projects.

Blocks

  • show title dialog: shows title, author, license, official website, and close controls above the stage.
  • show application menu: shows a stage-mounted menu for DSL open, reload, about, and close actions.
  • has saved DSL source?: reports whether localStorage contains a saved DSL source.
  • saved DSL file name: reports the stored DSL source file name.

Composition API

Host runtimes can import createTitleDialog, createApplicationMenu, and createDslStorage from @kubohiroya/turbowarp-title-menu, or use the TurboWarpTitleMenu global exposed by the standalone extension bundle.

Safety

The extension is unsandboxed because it mounts DOM controls and uses browser storage. Load reviewed builds only.

Development

See the repository README and architecture documentation for build, test, release, and compatibility details.

show title dialog

Shows the configured title dialog above the TurboWarp stage.

Block type: COMMAND. Opcode: showTitle. Permanent link

This block has no arguments.

show application menu

Shows the application menu above the TurboWarp stage.

Block type: COMMAND. Opcode: showMenu. Permanent link

This block has no arguments.

add app menu action [ACTION] labelled [LABEL]

Adds an application menu action this project owns, or relabels one it already added.

clear app menu actions

Removes every application menu action, including the built-in ones, so a project can define its own set.

Block type: COMMAND. Opcode: clearAppMenuActions. Permanent link

This block has no arguments.

show DSL file manager

Shows the dialog that adds, opens, renames, deletes, and sorts stored DSL files.

Block type: COMMAND. Opcode: showDslFiles. Permanent link

This block has no arguments.

when a DSL source is opened

Runs after the operator opens a stored DSL file, or after the opened source is announced again.

Block type: HAT. Opcode: whenDslSourceOpened. Permanent link

This block has no arguments.

reload the opened DSL source

Announces the currently opened DSL source again without showing a dialog.

Block type: COMMAND. Opcode: reloadOpenedDsl. Permanent link

This block has no arguments.

opened DSL file name

Returns the name of the DSL file that is currently open, or an empty string.

Block type: REPORTER. Opcode: openedDslName. Permanent link

This block has no arguments.

opened DSL source

Returns the text of the DSL file that is currently open, or an empty string.

Block type: REPORTER. Opcode: openedDslSource. Permanent link

has a saved DSL file?

Block type: BOOLEAN. Opcode: hasSavedDsl. Permanent link

Returns how many DSL files are stored in IndexedDB.
