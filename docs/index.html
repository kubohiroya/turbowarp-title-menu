TurboWarp Title Menu

Reusable title, menu, and DSL source storage controls for TurboWarp projects.

Blocks

  • show title dialog: shows title, author, license, official website, and close controls above the stage.
  • show application menu: shows a stage-mounted menu for DSL open, reload, about, and close actions.
  • has saved DSL source?: reports whether localStorage contains a saved DSL source.
  • saved DSL file name: reports the stored DSL source file name.

Composition API

Host runtimes can import createTitleDialog, createApplicationMenu, and createDslStorage from @kubohiroya/turbowarp-title-menu, or use the TurboWarpTitleMenu global exposed by the standalone extension bundle.

Safety

The extension is unsandboxed because it mounts DOM controls and uses browser storage. Load reviewed builds only.
